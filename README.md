## 📌 Featured Projects

Una selección de proyectos en los que he participado y que representan parte de mi experiencia desarrollando soluciones para diferentes necesidades.

### 🎓 EntrenaTec

Plataforma institucional orientada al **aprendizaje y gestión de cursos**, diseñada para centralizar contenidos educativos y facilitar la interacción entre estudiantes y maestros.

El sistema cuenta con diferentes **roles y permisos**, permitiendo adaptar las funcionalidades según el tipo de usuario. También incluye la gestión de cursos, contenidos y diferentes procesos relacionados con la formación.

### 🏥 NexaCore

Sistema desarrollado para apoyar la **gestión interna de IPS Clinical House**, centralizando diferentes procesos relacionados con la operación de la institución.

El proyecto abarca módulos enfocados en la **gestión de infraestructura, compras y sistemas**, permitiendo organizar y administrar información que anteriormente podía encontrarse distribuida entre diferentes procesos y herramientas.

### 💰 Daniq

Aplicación de **gestión financiera personal** enfocada en ayudar a llevar un mejor control sobre los ingresos, gastos y movimientos financieros.

Cuenta con un **coach financiero integrado** que acompaña al usuario durante el registro de sus transacciones, proporcionando contexto y recomendaciones para facilitar el seguimiento de sus hábitos financieros y tomar mejores decisiones.
